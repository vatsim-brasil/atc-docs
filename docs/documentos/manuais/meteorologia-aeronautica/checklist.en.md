# Checklist

## Pre-briefing (5 minutes)

- [ ] Define the operating window (ETD/ETA) in **UTC**
- [ ] List the aerodromes: departure, destination, alternates

## NOTAM (AISWEB)

- [ ] Runway: closures, works, intersections, RWY CCND, limits
- [ ] Navaids: ILS/VOR/NDB/GBAS, lights, PAPI/VASI
- [ ] Procedures: SID/STAR/APP, temporary restrictions
- [ ] Airspace: segregated/activated areas, events
- [ ] Services: ATIS, local weather, operating hours

## METAR/SPECI (REDEMET)

- [ ] Wind (including gusts and variation)
- [ ] Visibility / RVR (when applicable)
- [ ] Phenomena (TS/RA/FG/BR/DZ)
- [ ] Ceiling (lowest BKN/OVC)
- [ ] QNH
- [ ] Immediate trend (recent SPECI?)

## TAF (REDEMET)

- [ ] Check the window for your ETA
- [ ] Identify the worst case in `TEMPO` and `PROB`
- [ ] Check the forecast wind (runway change?)
- [ ] Check TS/CB/rain and ceiling/visibility

## Decision

- [ ] Minima and alternates met?
- [ ] Fuel: realistic holding and alternate?
- [ ] Convective window: tactical adjustment (depart earlier/later)?
- [ ] Rebrief before pushback/taxi
