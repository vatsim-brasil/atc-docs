# Quick checklists (TWR)

## Checklist — Setting up circuit operation (no VAC)

1. Confirm the **runway in use** (wind/safety)
2. Define the circuit **direction**: standard **left-hand**
3. Define **altitudes** by category:
   - piston: 1000 ft AAL
   - jet: 1500 ft AAL
   - helicopter: 500 ft AAL (route/low circuit)
4. Define **minimum reports**: downwind / base / final
5. Define **integration rules**: join downwind as the standard
6. Define how to handle **straight-in** (allow only if there is no conflict)
7. Define how to handle **crossing final** (avoid; coordinate explicitly)

## Checklist — Sequencing mixed traffic

- If a jet closes up on a piston:
  - put the jet higher and/or further out,
  - extend the downwind of the faster one,
  - avoid "tightening the base" of the slower one.
- Helicopter:
  - keep below and clear of the fixed-wing traffic axis,
  - cross final only with final clear.

## Checklist — When to simplify (reduce workload)

- traffic increasing: standardise join downwind + fixed reports
- separate by altitude and side
- use "extend downwind leg" instead of multiple small instructions
- avoid releasing simultaneous joinings without confirmed visual contact
