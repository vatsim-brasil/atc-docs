# Quick checklist

Use this list to avoid the errors that most often hold up the flow (both in real-world ATS and on networks).

## Consistency check

- [ ] **ITEM 7** has up to 7 characters and matches the callsign you intend to use
- [ ] **ITEM 8** (IFR/VFR) is consistent with your route (IFR SID/STAR etc.)
- [ ] **ITEM 9** uses an ICAO designator (Doc 8643). If `ZZZZ`, there is a `TYP/` in ITEM 18
- [ ] **ITEM 10** does not promise equipment you are not going to use
- [ ] **ITEM 13** has a **4-letter ICAO** code. If `ZZZZ`, there is a `DEP/` in ITEM 18
- [ ] **ITEM 15** has a consistent speed + level (and VFR with `RMK/` when necessary)
- [ ] **ITEM 16** has destination + total duration (HHMM). If `ZZZZ`, there is a `DEST/` in ITEM 18
- [ ] Alternates are consistent (or blank according to practice/rules). If `ZZZZ`, there is an `ALTN/`
- [ ] If there is a remark, use **`RMK/`** (avoid loose text without an indicator)

## Operational checklist (simulation)

- [ ] METAR/TAF reviewed (to select the runway and alternates)
- [ ] SID/STAR compatible with RNAV/PBN (if applicable)
- [ ] Planned fuel consistent with EET + reserves
- [ ] Transponder, altimeter, radios and navigation set up according to the plan
