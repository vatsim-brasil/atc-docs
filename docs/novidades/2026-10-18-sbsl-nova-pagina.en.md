# New SBSL page

The São Luís page was rewritten from the current AIP AD 2 SBSL. It now shows that only runway 06/24 is in use (the former 09/27 is closed), explains the DCL run by Tower (the only package position besides the ATIS) and adds the ground flow with diagrams for runways 06 and 24: with no parallel taxiway, every departure enters via A and backtracks to the threshold. It also covers runway exits, takeoff points and a table of aprons and airlines. The transition altitude is now 10000 ft and the largest code accepted is 4C, per the AIP and the IAC charts.
