# AIRAC Updates

What changed in the sector files of the Vatsim Brasil FIRs in each AIRAC cycle: navigation data, procedures, sectors, ground layouts and plugins.

The packages are published on [AeroNav](https://files.aero-nav.com/SBXX), but you should download and update them with the **[Sector File Manager](https://github.com/VectorsATCGroup/euroscope-sector-file-manager)**, as the division has standardized. See how to install them and keep them up to date in [EuroScope installation](../../fundamentos/softwares/euroscope/instalacao.md#keep-the-files-up-to-date).
