# Atualizações de AIRAC

O que mudou nos arquivos de setor das FIRs da Vatsim Brasil a cada ciclo AIRAC: dados de navegação, procedimentos, setores, diagramas de solo e plugins.

Os pacotes são publicados no [AeroNav](https://files.aero-nav.com/SBXX), mas o download e a atualização devem ser feitos pelo **[Sector File Manager](https://github.com/VectorsATCGroup/euroscope-sector-file-manager)**, como a divisão padronizou. Veja como instalar e manter os arquivos em dia em [Instalação do EuroScope](../../fundamentos/softwares/euroscope/instalacao.md#mantenha-os-arquivos-atualizados).
