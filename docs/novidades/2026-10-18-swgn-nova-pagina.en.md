# New SWGN page

FIR Amazônica now has a page for Araguaína (SWGN), the last Brazilian aerodrome from the SBAZ package that was still missing. The page has the general data, the transition altitude from the current charts, runway 09/27, the Araguaína Radio position and the ROTAER rules that apply on VATSIM.
