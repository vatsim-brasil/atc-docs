## :material-routes: Runways

### Runway system

SBCY has **one runway**, 17/35 (2300 × 45 m, asphalt). **E** runs along the runway on the west side, from in front of apron 1 to **D**, at threshold 35. **There is no taxiway to threshold 17**: departures from 17 enter via **A** and backtrack. Both thresholds have a turn pad.

<div class="grid cards" markdown>

-   :material-airplane:{ .lg .middle } **Runway `17`**

    ---

    RNP and VOR. Departure from the threshold, backtracking from A.

-   :material-airplane:{ .lg .middle } **Runway `35`**

    ---

    ILS CAT I. Departure from the threshold, via D.

</div>

!!! info "Runway selection"
    The AIP sets no preferential runway: the runway in use follows the wind.

### Runway data

| Runway | Dimensions | TORA | LDA | Approach | Remarks |
| :---: | :---: | :---: | :---: | :---: | :--- |
| **17** | 2300 × 45 m | 2300 m | 2300 m | Non-precision | RNP and VOR |
| **35** | 2300 × 45 m | 2300 m | 2300 m | ILS CAT I | The only ILS at the aerodrome |

- The AD accepts aircraft up to code **4C**[^ad20-1].
- **No 180° turns** on the runway for medium and large aircraft: only on the **threshold turn pads**, because the runway is degraded[^ad20-6].

[^ad20-1]: [AIP Brasil, AD 2 SBCY 2.20, item 1](https://aisweb.decea.mil.br/?i=publicacoes&p=aip). Declared distances: AD 2.13.
[^ad20-6]: [AIP Brasil, AD 2 SBCY 2.20, item 6](https://aisweb.decea.mil.br/?i=publicacoes&p=aip).

| **SBCY_TWR** | `TCY` | Cuiabá Tower | **118.100** | |

### DCL

SBCY has **DCL** (departure clearance via datalink)[^ad18]. On the network, the station code is **`SBCY`**. The AIP lists Cuiabá Clearance as datalink only, and there is no Clearance Delivery (DEL) position: **Ground** issues the clearances.

| | |
| :--- | :--- |
| **Station code** | `SBCY` |
| **Who operates it** | SBCY_GND. Without GND, the position covering clearance top-down (TWR, APP or ACC) |
| **Controller tool** | TopSky DCL window, with your personal Hoppie ACARS code |
| **Pilot tool** | Aircraft ACARS or a Hoppie-compatible client, sending the clearance request to `SBCY` |

**How it works:**

1. The pilot sends the request (RCD) to `SBCY`, with the parking stand and ATIS letter.
2. The controller checks the flight plan and replies with the clearance: limit, runway, SID, transponder code, ATIS letter and next frequency.
3. The pilot accepts (`WILCO`/`ACCEPT`). The clearance is then issued and **there is no voice readback**.
4. With the clearance accepted, the pilot calls Ground for start-up or pushback.

!!! tip "Controller setup"
    - Log in to the TopSky DCL with the code `SBCY` before opening the position.
    - Announce it in the controller information: `DCL AVBL LOGON SBCY`.
    - A faulty request (invalid plan, wrong SID, no ATIS) goes back as **REVERT TO VOICE**: the pilot calls Ground on frequency.
    - If the pilot does not accept within a reasonable time, consider the clearance not delivered and call them by voice.

[^ad18]: [AIP Brasil, AD 2 SBCY 2.18](https://aisweb.decea.mil.br/?i=publicacoes&p=aip).

  ![Map of SBCY with the runway strip in yellow, under Tower, and the rest in blue, under Ground](img/sbcy-responsabilidade.svg){ loading=lazy }
  <figcaption>Yellow strip: Tower. Rest: Ground. The dashed line runs through the holding points. Circles: aprons.</figcaption>

| Position | Responsible for |
| :--- | :--- |
| **GND** | Aprons 1 and 2, TWY **E**, **F**, **G** and the links up to the **holding point** |
| **TWR** | Runway 17/35, the threshold turn pads and the TWY inside the holding points |

- SBCY **has no Apron position** (APRON): Ground handles both aprons.
- **Departures:** Ground hands off to Tower **before the holding point**. For 17, Tower clears the aircraft to enter via A and backtrack to the threshold. **Arrivals:** after vacating the runway, Tower hands off to Ground.

## :material-transit-connection-variant: Ground flow

!!! abstract "General rule"
    - **E** runs along the runway on the west side: it passes in front of aprons 1 and 2 and continues to **D** (threshold 35).
    - **A**, **B** and **C** link E with the middle of the runway. **C** is narrow (9 m) and only takes **code A** aircraft[^ad8].
    - **F** and **G** lead to the south sector hangars, also **code A** only. F is day use only[^ad8].
    - Pushback is **mandatory** for aircraft above 20 t[^ad20-2].

=== "Runway 17"

    <figure markdown="span">
      ![Ground flow on runway 17: departures via E and A, backtracking to threshold 17; landings roll to the end, vacate via D and return along E](img/sbcy-fluxo-17.svg){ loading=lazy }
      <figcaption>Green: departures. Dashed orange: exit via C (code A). Blue: landings.</figcaption>
    </figure>

    - **Departures (17):** **E** to **A**, enter the runway and **backtrack** to threshold 17, turning on the turn pad.
    - **Landings (17):** roll to the end, vacate via **D** and return along **E**. Code A aircraft may vacate via **C** (~1320 m).

    Example: `AZU4321, taxi to holding point runway 17 via E and A.` Tower follows with: `AZU4321, enter runway 17 via A and backtrack.`

=== "Runway 35"

    <figure markdown="span">
      ![Ground flow on runway 35: departures via E to D; landings vacate via B or A and return to the aprons along E](img/sbcy-fluxo-35.svg){ loading=lazy }
      <figcaption>Green: departures. Dashed orange: alternatives (A and, for code A, C). Blue: landings.</figcaption>
    </figure>

    - **Departures (35):** **E** southbound to **D** (threshold 35).
    - **Landings (35):** vacate via **B** (~1290 m) and follow E to apron 2, or further on via **A** (~1460 m), in front of apron 1. Code A aircraft may vacate via **C** (~980 m).

    Example: `GLO1234, taxi to holding point runway 35 via E and D.`

### Runway exits

| Runway | Exits |
| :---: | :--- |
| **17** | **C** (~1320 m, code A only) or **D** (end) |
| **35** | **C** (~980 m, code A only), **B** (~1290 m) or **A** (~1460 m) |

<small>Approximate distance from the threshold to the exit, measured on the diagram. The SBCY AIP publishes no exits.</small>

!!! warning "In IMC"
    While a **code 3 or 4** aircraft is landing or taking off, the following are prohibited[^ad20-2]:

    - aircraft movement on **E**;
    - **pushback**.

[^ad20-2]: [AIP Brasil, AD 2 SBCY 2.20, item 2](https://aisweb.decea.mil.br/?i=publicacoes&p=aip).

## :material-clipboard-text-outline: Other procedures

- Fixed-wing traffic pattern: minimum height **1100 ft** above the aerodrome. Helicopters: **700 ft**[^ad20-1].
- Landings and takeoffs at SWLV, SSGC, SJCY, SIAQ, SWXJ and SIXM: two-way contact with **Cuiabá Approach** is mandatory[^ad22].
