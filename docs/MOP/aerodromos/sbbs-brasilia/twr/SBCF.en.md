## :material-routes: Runways

### Preferential runway system

SBCF has **one runway**, 16/34 (3600 × 45 m, asphalt). **TWY A** runs along the runway on the east side, between it and the aprons, end to end.

<div class="grid cards" markdown>

-   :material-airplane:{ .lg .middle } **Preferential: `16`**

    ---

    Landings and takeoffs. ILS CAT I.

-   :material-airplane:{ .lg .middle } **Alternative: `34`**

    ---

    Used when the wind rules out 16. ILS CAT I.

</div>

!!! warning "Preferential system"
    With {==**a tailwind component of up to 7 kt**==} and a **dry runway**, the runway in use is **16**[^ad20-10].

    With 16 in use and a tailwind, pilots who request 34 should expect a **delay** in landing or takeoff[^ad20-10].

### Runway data

| Runway | Dimensions | TORA | LDA | Approach | Remarks |
| :---: | :---: | :---: | :---: | :---: | :--- |
| **16** | 3600 × 45 m | 3600 m | 3600 m | ILS CAT I | 300 m CWY |
| **34** | 3600 × 45 m | 3600 m | 3600 m | ILS CAT I | 1400 m CWY |

- The AD accepts aircraft up to code **4E**[^ad20-1].
- 180° turns for code **C, D and E** aircraft only at the **thresholds**[^ad20-6].
- On approach to 34, **do not confuse** it with Lagoa Santa aerodrome (SBLS), to the right of the track[^ad23].

[^ad20-1]: [AIP Brasil, AD 2 SBCF 2.20, item 1](https://aisweb.decea.mil.br/?i=publicacoes&p=aip).
[^ad20-6]: [AIP Brasil, AD 2 SBCF 2.20, item 6](https://aisweb.decea.mil.br/?i=publicacoes&p=aip).
[^ad20-10]: [AIP Brasil, AD 2 SBCF 2.20, item 10](https://aisweb.decea.mil.br/?i=publicacoes&p=aip). Declared distances: AD 2.13.

### DCL

SBCF has **DCL** (departure clearance via datalink)[^ad18]. On the network, the station code is **`SBCF`**. Equipped aircraft must request their clearance through DCL[^ad20-12].

| | |
| :--- | :--- |
| **Station code** | `SBCF` |
| **Who operates it** | SBCF_DEL. Without DEL, the position covering clearance top-down (GND, TWR, APP or ACC) |
| **Controller tool** | TopSky DCL window, with your personal Hoppie ACARS code |
| **Pilot tool** | Aircraft ACARS or a Hoppie-compatible client, sending the clearance request to `SBCF` |

**How it works:**

1. The pilot sends the request (RCD) to `SBCF`, with the parking stand and ATIS letter.
2. The controller checks the flight plan and replies with the clearance: limit, runway, SID, transponder code, ATIS letter and next frequency.
3. The pilot accepts (`WILCO`/`ACCEPT`). The clearance is then issued and **there is no voice readback**.
4. With the clearance accepted, the pilot calls Ground for start-up or pushback.

!!! tip "Controller setup"
    - Log in to the TopSky DCL with the code `SBCF` before opening the position.
    - Announce it in the controller information: `DCL AVBL LOGON SBCF`.
    - A faulty request (invalid plan, wrong SID, no ATIS) goes back as **REVERT TO VOICE**: the pilot calls Clearance on frequency.
    - If the pilot does not accept within a reasonable time, consider the clearance not delivered and call them by voice.

[^ad18]: [AIP Brasil, AD 2 SBCF 2.18](https://aisweb.decea.mil.br/?i=publicacoes&p=aip).

<figure markdown="span">
  ![Map of SBCF with the runway strip in yellow, under Tower, and the rest in blue, under Ground](img/sbcf-responsabilidade.svg){ loading=lazy }
  <figcaption>Yellow strip: Tower. Rest: Ground. The dashed line runs through the holding points. White circles: apron numbers.</figcaption>

| Position | Responsible for |
| :--- | :--- |
| **GND** | Aprons 1 to 4, TWY **A** and the links up to the **holding point** |
| **TWR** | Runway 16/34 and the TWY inside the holding points |

- SBCF **has no Apron position** (APRON): Ground handles all aprons.
- **Departures:** Ground hands off to Tower **before the holding point**. Pilots reach the holding point ready for departure; if not, they tell Ground[^ad20-12].
- **Arrivals:** after vacating the runway, Tower hands off to Ground.

## :material-transit-connection-variant: Ground flow

!!! abstract "General rule"
    - **TWY A** runs along the runway on the east side and reaches both thresholds: via **B** at 16 and via **P** (or **N**) at 34.
    - **C2** links apron 2 with A; **F2** links apron 1. **C1** and **F1** are the rapid exits.
    - **R**, **S** and **T** run along aprons 1 and 2, in front of the terminals; **E** cuts between the remote stands.
    - **J**, **L** and **M** link apron 3 (cargo) with A. **Q** between aprons 3 and 4 is **closed**[^ad28].
    - Wingspan of **17 m or more**, piston or jet: stands are left with **pushback**[^ad20-2].

=== "Runway 16"

    <figure markdown="span">
      ![Ground flow on runway 16: departures via C2 and A to B; code A/B from C1; landings vacate via F1 and follow F2 to apron 1](img/sbcf-fluxo-16.svg){ loading=lazy }
      <figcaption>Green: departures. Dashed orange: intersection departure (code A/B). Blue: landings.</figcaption>
    </figure>

    - **Departures (16):** **A** northbound to **B** (threshold 16).
    - **Code A/B:** departs from **C1** (TORA 2720 m)[^ad20-12].
    - **Landings (16):** vacate via **F1** (~1765 m) and follow **F2** to apron 1[^ad20-11].

    Example: `GLO1234, taxi to holding point runway 16 via A, B.`

=== "Runway 34"

    <figure markdown="span">
      ![Ground flow on runway 34: departures via F2 and A to P; code A/B from H; landings vacate via C1 and follow C2 to apron 2](img/sbcf-fluxo-34.svg){ loading=lazy }
      <figcaption>Green: departures. Dashed orange: intersection departure (code A/B). Blue: landings.</figcaption>
    </figure>

    - **Departures (34):** **A** southbound to **P** (threshold 34).
    - **Code A/B:** departs from **H** (TORA 2987 m)[^ad20-12].
    - **Landings (34):** vacate via **C1** (~2700 m) and follow **C2** to apron 2[^ad20-11].

    Example: `AZU4321, taxi to holding point runway 34 via A, P.`

### Runway exits

Pilots must vacate the runway **completely** before stopping, via the listed exit, or tell APP or Tower if they cannot use it[^ad20-11].

| Runway | Exits |
| :---: | :--- |
| **16** | **F1** (1765 m), **H** (~2950 m) or **N**/**P** (end) |
| **34** | **H** (~650 m, light aircraft), **C1** (2700 m) or **B** (end) |

<small>Approximate distance from the threshold to the exit. F1 and C1: AIP; the others measured on the diagram.</small>

### Taxi restrictions

| Restriction | Where |
| :--- | :--- |
| **TWY Q closed** | Between aprons 3 and 4[^ad28] |
| **180° turns** | Code C, D and E only at the thresholds[^ad20-6] |
| **Pushback required** | Wingspan of 17 m or more, piston or jet, at any stand[^ad20-2] |
| **Self-manoeuvring out of the stand** | Stands 216 to 225: wingspan up to 14.99 m and the C208, turning 180° to the left; 15 to 17 m (216 to 224 only), with the adjacent stand free[^ad20-2] |

[^ad20-2]: [AIP Brasil, AD 2 SBCF 2.20, item 2](https://aisweb.decea.mil.br/?i=publicacoes&p=aip).
[^ad28]: [AIP Brasil, AD 2 SBCF 2.8](https://aisweb.decea.mil.br/?i=publicacoes&p=aip) and ADC chart.

## :material-airplane-takeoff: Takeoff points

<figure markdown="span">
  ![Overview of SBCF with numbered aprons and the takeoff points marked with the available TORA](img/sbcf-visao-geral.svg){ loading=lazy }
  <figcaption>Takeoff points (purple) with the available TORA. Circled numbers: aprons.</figcaption>
</figure>

| Runway | Point | TORA | Used by |
| :---: | :---: | :---: | :--- |
| **16** | **B** (threshold) | 3600 m | Code C or larger |
| **16** | **C1** | 2720 m | Code A and B[^ad20-12] |
| **34** | **P** (threshold) | 3600 m | Code C or larger |
| **34** | **H** | 2987 m | Code A and B[^ad20-12] |

- Code A and B depart from the intersection. Those who cannot say so **when requesting their clearance**. Code C or larger may request the intersection or be instructed by Tower[^ad20-12].
- Pilots reach the holding point **ready for departure**; **immediate** line-up and takeoff roll within **10 seconds** of the clearance[^ad20-12].
- Tower does not give the takeoff time; the next unit's frequency comes with the takeoff clearance[^ad20-12].
- **Only when instructed by Tower**, call APP right after takeoff with only `BELO HORIZONTE CONTROL, [CALLSIGN]`[^ad20-12].
- Turboprops and piston aircraft expect **vectors** or a **direct** to a waypoint right after takeoff[^ad20-12].

## :material-speedometer: HIRO

**HIRO** (high-intensity runway operations) cuts runway occupancy time to shorten the spacing on final, between departures and between landings and departures[^ad20-11].

| | |
| :--- | :--- |
| **Activation** | Broadcast on the **ATIS**; only in visual conditions with a dry runway |
| **Approach speed** | **170 to 150 kt** at 5 NM from the threshold; slow down for final only after the 5th mile. ATC-assigned speeds are mandatory |
| **Landing** | Vacate the runway **completely** before stopping: **F1** on 16, **C1** on 34. If unable, tell APP or Tower |
| **Takeoff** | Request through DCL; code A and B from **C1** (16) or **H** (34) |

[^ad20-11]: [AIP Brasil, AD 2 SBCF 2.20, item 11](https://aisweb.decea.mil.br/?i=publicacoes&p=aip).
[^ad20-12]: [AIP Brasil, AD 2 SBCF 2.20, item 12](https://aisweb.decea.mil.br/?i=publicacoes&p=aip).
