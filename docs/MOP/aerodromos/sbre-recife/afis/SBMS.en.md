## :material-airplane-takeoff: Operations

### Aerodrome Regulations

- The AD may be used regularly by any ACFT compatible with reference code 2C or lower.
- OPS of ATR-72 ACFT (reference code 3C) in IMC PRB.
- HEL TFC circuit only in SECT SE of the AD, at 600FT HGT.

### Aprons and Taxiways

- TWY `B` CLSD for night OPS of reference code C ACFT.

### Runways

- 180° turns of ACFT with a wingspan greater than 24M only at the THR.

### Additional Information

- ERAA on FREQ 132.350 MHz H24, except while the Radio is operating.
- Concentration of birds on RWY 05/23 and in the vicinity of THR 05.
